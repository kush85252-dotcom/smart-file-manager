# Contributing to Smart File Manager

Thanks for your interest in contributing to Smart File Manager.

## Before Contributing

* Check existing issues before opening a new one.
* Keep changes focused and easy to review.
* Do not add unnecessary dependencies.
* Keep Smart File Manager local-first and privacy-friendly.
* Do not add AI features to the core application without discussion.

## Reporting Bugs

When reporting a bug, include:

* What happened
* What you expected to happen
* Steps to reproduce the issue
* Windows version
* Smart File Manager version
* Relevant error messages or logs

## Pull Requests

1. Fork the repository.
2. Create a branch for your change.
3. Make and test your changes.
4. Commit your changes with a clear message.
5. Open a pull request with a description of what changed.

Please keep pull requests focused on one feature, fix, or improvement.

## Code

Use clear Python code and keep the existing project structure where possible.

## Questions

For questions or ideas, open a GitHub Discussion or issue when appropriate.
