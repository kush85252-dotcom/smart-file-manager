# Security Policy

## Supported Versions

Security updates are currently provided for the latest release of Smart File Manager.

| Version        | Supported |
| -------------- | --------- |
| Latest release | Yes       |
| Older releases | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in Smart File Manager, please report it privately rather than opening a public GitHub issue.

Include:

* A clear description of the vulnerability
* Steps to reproduce it
* The affected version
* The potential impact
* Any relevant screenshots, logs, or proof of concept

Please do not publicly disclose the vulnerability until it has been reviewed and a fix or mitigation is available.

## Security Considerations

Smart File Manager is designed to work locally on the user's computer.

Users should:

* Download Smart File Manager only from trusted sources.
* Keep the application updated.
* Review file operations before allowing them to run automatically.
* Avoid running untrusted files with administrator privileges.

## Scope

This policy covers security vulnerabilities in Smart File Manager and its official repository.

For general bugs or feature requests, please use GitHub Issues instead.
