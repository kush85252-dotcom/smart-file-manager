# Changelog

All notable changes to **Smart File Manager** are documented here.

---

## [1.5] — Major UI & Architecture Update

> **Note:** Smart File Manager is jumping directly to **v1.5** for this major update.

### Added

* **Major UI overhaul**

  * Cleaner and more modern interface
  * Improved navigation and usability
  * Better organization of file-management features

* **Built-in File Explorer**

  * Browse files and folders directly inside Smart File Manager
  * Improved navigation between directories

* **Right-Click Context Menu**

  * Added context actions for files and folders
  * Faster access to common file-management operations

* **Improved Safety System**

  * Safer file operations
  * Better handling of potentially destructive actions
  * Additional protection against accidental file changes

### Improved

* Refactored core code for better structure and maintainability
* Improved overall application stability
* Cleaner internal architecture
* Improved file and folder handling
* Better separation between UI and application logic
* General performance and reliability improvements

### Fixed

* Various bugs discovered during the v2 development/refactoring process
* Improved handling of file-management edge cases
* Fixed issues affecting UI interactions and file operations

### Known Issues

* Some edge cases may still occur with unusual file permissions or protected system directories.
* Additional improvements and bug fixes are planned for future releases.
