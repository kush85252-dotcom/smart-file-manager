# Code of Conduct

## Our Pledge

We are committed to making participation in the Smart File Manager community a welcoming and respectful experience for everyone.

By participating in this project, you agree to:

* Be respectful and kind.
* Give constructive feedback.
* Help create a positive environment.
* Respect different opinions and experiences.
* Focus on improving the project together.

---

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment or personal attacks.
* Hate speech or discrimination.
* Trolling or intentionally disruptive behavior.
* Spam or malicious content.
* Sharing private information without permission.

---

## Contributing Respectfully

When contributing to Smart File Manager:

* Keep discussions professional.
* Explain bug reports clearly.
* Write constructive feature requests.
* Review code respectfully.
* Be patient with maintainers and contributors.

---

## Reporting Issues

If you experience or witness unacceptable behavior, please open a private discussion or contact the project maintainer.
