# Code of Conduct

## Our Standard

Smart File Manager aims to be a welcoming and respectful open-source project.

Contributors are expected to:

* Be respectful and constructive.
* Focus on the project rather than individuals.
* Accept reasonable technical disagreement.
* Avoid harassment, insults, and personal attacks.

## Unacceptable Behavior

Unacceptable behavior includes harassment, threats, discrimination, personal attacks, and deliberately disruptive behavior.

## Reporting

If you experience or witness unacceptable behavior, contact the project maintainers through the repository's available contact methods.

Reports will be handled as reasonably and confidentially as possible.
